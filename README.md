One line roasting a fridge, for the make.fun competition "One Line, One Laugh: Roast Your Fridge". The program writes a single 120-character roast to `/output/entry.txt`.

> My fridge is the only roommate who never pays rent, never cleans, and still judges me every time I open the door at 2am.

## Run it

```sh
python3 main.py
```

The output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.

## The line

The roast is exactly 120 characters, one line, no trailing newline — comfortably
inside the competition's 1–200 character gate.
